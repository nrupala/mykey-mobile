Pair this browser with MyKey

Pairing lets this browser extension fill logins from the MyKey app on this computer. It takes two short steps, and you approve it on the desktop — nothing pairs itself.

Step 1 — give the desktop this browser's pairing payload

On the desktop, in a terminal, run mykey ext-enroll --payload payload.json with this payload saved as the file (or paste it when asked). First, compare: the fingerprint must match on both screens.

Step 2 — pin the desktop's host key

On the desktop run mykey ext-host-payload and paste its output here. MyKey checks the fingerprint against the key itself — a payload that lies about its fingerprint is refused.

Then, once, on the desktop

  1. mykey ext-set-vault <path to your vault.mykey> — tell the host which vault to serve.
  2. mykey ext-host-install — let this browser start the host.

To unpair: mykey ext-revoke on the desktop ends it for good. This browser's key can never be re-approved after a revoke — reset the identity below and pair afresh.

Reset this browser's pairing identity

Makes a brand-new key for this browser. Every existing pairing for the old key stops working.
